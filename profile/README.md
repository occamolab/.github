# OccamoLab

A research group composing neural networks with known laws: small, exact, auditable models.

**Website:** [occamolab.org](https://occamolab.org) · **Paper:** [arXiv:2611.12567](https://arxiv.org/abs/2611.12567) · **Code:** [lawkan](https://github.com/occamolab/lawkan)

## Research interests

- Group-law layers and geometric deep learning
- Robot-arm calibration and inertial navigation
- Parameter-efficient models for edge and embedded deployment
